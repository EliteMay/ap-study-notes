# AP Study Guide 仕様書

## 1. 位置付け

応用情報技術者試験（AP）の学習用静的Webアプリ。

- Repository: `EliteMay/ap-study-guide`
- Public: `https://elitemay.github.io/ap-study-guide/`
- 正式要件のSource of Truth: Repository Root `REQUIREMENTS.md`
- Build / Project Profile正本: `json/project-meta.json`
- 制作Guide: `EliteMay/web-project-guide`
- Project Memory: `PROJECT_LEARNINGS.md`
- 基準: IPA 応用情報技術者試験 シラバス Ver.7.2
- 技術: HTML / CSS / JavaScript / JSON
- Deployment: GitHub Pages

Project Profile: `STATIC + DATA + LEARNING + TOOL + PUBLIC-CONTENT`

## 2. Product Goal

初学者が単語だけを暗記するのではなく、仕組み・理由・具体例まで理解し、問題演習と復習へつなげてAP合格水準へ近づけること。

基本導線:

**Home → Lesson → 途中確認 → 末尾確認 → 関連短問 → Case / Mock → 公開公式問題 → 弱点復習**

分からない内容は横断検索からLesson・用語・問題へ戻る。

## 5. Home

Page: `index.html`  
Runtime: `js/home.js`

責務:

- 今日の優先学習を表示

## 6. 横断検索

Page: `html/search.html`  
Runtime: `js/search.js`  
Style: `css/search.css`

検索対象:

- Lesson
- 用語
- 短問
- 学習分野
- 公開公式問題

検索仕様:

1. 完全一致のLesson ID / Title / Term Aliasを優先
2. 前方一致
3. Title部分一致
4. 説明・Keyword部分一致

読み込み仕様:

- Lesson / Unit: 初期Catalog
- Terms / Practice / Official: 検索実行時に遅延読込
- Search Page以外の初期表示へ重い横断Catalogを混ぜない

結果0件でも単語辞書へのFallbackを表示する。

## 8. Lesson

Page: `html/lesson.html?id=<LESSON_ID>`  
Base Runtime: `js/lesson.js`  
Phase 1補助Runtime: `js/lesson-phase1.js`

### 8.1 既存保存Contract

- Progress Key: `ap-study-lesson-progress-v1`
- 末尾確認問題を全問回答
- 75%以上で現行の「理解確認済み」
- 現行Runtimeでは14日後に再確認対象

Phase 2導入まで、このKeyと判定を名称変更だけの理由で変更しない。

### 8.2 Phase 1 Lesson Contract

Phase 1対象Lessonは原則として次を持つ。

- importance
- frequency
- examFocus
- prerequisiteLessons
- relatedLessons
- relatedTerms
- relatedPracticeRefs
- officialProblemRefs
- 学習目標
- 十分な本文Section
- 必要な図解 / 比較 / Trace
- よくある誤解
- inlineChecks
- 末尾確認問題

Phase 1 Metadataは、既存Lesson JSONの`meta`へ直接持たせてもよいし、既存本文を大量書換えしない方が安全な場合は `json/phase1/index.json` から該当Unitの補助JSONを遅延読込してOverlayしてよい。

`inlineChecks` は学習途中の理解確認で、現行の学習進捗には保存しない。保存対象の理解判定は末尾確認問題が担当する。

補助範囲Reviewと公開公式問題Mapping不足が残るため、**Algorithm / Programming Unitを完成済みとは扱わず `pilot` を維持する。**

## 13. Migration

Phase 1 Pilot Contract:

- Foundation: `json/migrations/lesson-phase1-r26.json`
- Algorithm / Programming: `json/migrations/lesson-phase1-algorithm-r27.json`

両Pilotで次を維持する。

- Lesson ID
- Unit ID
- `lesson.html?id=<ID>` URL
- Lesson Progress Key
- Practice History Key
- Case History Key
- Mock History Key

現在はIdentity Migrationのみ。

将来Lesson merge / split / moveを行う場合:

1. 旧ID / URL / Progress / Mappingを列挙
2. 新IDへMapping
3. 進捗統合 / 配分Ruleを定義
4. Backup / Rollback可能にする
5. Validator追加
6. 分野単位のValidation後に切替
